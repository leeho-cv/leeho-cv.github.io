2026.09—2026.10独立设计与开发

支持长任务执行与多 Agent 协作的本地编程智能体（LeeAgent）

  • 采用 C/S 架构，通过 TCP 长连接实现 CLI/TUI 与后台服务之间的命令调用和事件推送。后台服务异步执行模型调用与工具调度，与客户端连接解耦。
  • 基于类型化事件总线按任务和会话维度实时推送模型输出与工具事件，支持历史回放、实时订阅，以及断线重连后的事件补发与去重。
  • 封装兼容 OpenAI 协议的模型调用层，实现 ReAct 式 Agent Loop 和统一工具调度，接入文件读写、Bash 执行和任务清单等工具，支持多轮工具调用与错误反馈自纠正。
  • 通过会话持久化、历史续接和上下文压缩支持长任务；构建父子 Agent 协作机制，为子 Agent 配置独立上下文与事件总线，通过事件桥接同步执行过程并回传结果，支持 Markdown Skills 加载和 MCP 工具接入。
  • 建立覆盖 IPC 通信、领域事件和模型调用的三层 Trace，按运行 ID 和轮次追踪执行过程、Token 用量与耗时。
